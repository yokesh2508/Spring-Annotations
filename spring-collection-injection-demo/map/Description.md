A Spring Core project demonstrating **Map Collection Injection** using Java-based configuration.
This project showcases how to create and inject multiple `Map<Integer, String>` beans using 
`@Bean`, `@Autowired`, and `@Qualifier`. 
It also demonstrates annotation-based configuration with `@Configuration` and `@ComponentScan`
by injecting different product collections into a `Products` class through the Spring IoC Container.
