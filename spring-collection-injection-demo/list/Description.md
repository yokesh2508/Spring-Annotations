A Spring Core project demonstrating Collection Injection using Java-based configuration. 
This project showcases how to create and inject multiple `List<String>` beans using 
`@Bean`, `@Autowired`, and `@Qualifier`. It also demonstrates annotation-based c
onfiguration with `@Configuration` and `@ComponentScan` by injecting different 
cast and crew lists into a `Movie` class through the Spring IoC Container.
